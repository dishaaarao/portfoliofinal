# portfoliofinal

Modern, ultra-responsive developer & UI/UX portfolio web application for **Disha Rao**, built with React 18, Vite, Lucide Icons, and Glassmorphism CSS.

## 🚀 Features

- **Glassmorphism UI System**: Custom CSS variables for seamless dark and light mode themes.
- **Hero & Personal Branding**: Status availability indicator, social handles, and floating card badges.
- **Interactive Skills Matrix**: Categorized tech stack with progress bar animations.
- **Filterable Projects**: Category filters, live demo links, source code links, and detailed preview modals.
- **Career Timeline**: Work history and academic background timeline.
- **Contact & Toast Feedback**: Click-to-copy email badge and interactive contact form with instant notifications.

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Custom Design Tokens, Glassmorphism, Responsive Breakpoints)

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/dishaaarao/portfoliofinal.git

# Navigate into project directory
cd portfoliofinal

# Install dependencies
npm install

# Start local dev server
npm run dev
```
